# One Move Chess

The repository is intentionally a foundation only. It contains no playable game, pages, or chess business logic yet.

## Packages

- `apps/web`: React, TypeScript, and Vite client.
- `apps/api`: future Fastify, Prisma, PostgreSQL, and Socket.IO server.
- `packages/contracts`: framework-neutral types and schemas shared across the network boundary.

See [ARCHITECTURE.md](ARCHITECTURE.md) for the intended feature boundaries and future design.
